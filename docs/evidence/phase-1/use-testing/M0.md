**Tester:** use-testing session (scripted Playwright journeys, headless Chromium 1.65.2) · **Build:** 0.1.0 (QA stack http://localhost:8180, worktree commit 56b2ed2), run 2026-11-16 · **Theme and mode:** light, dark and high-contrast (M0-05) · **Input method:** keyboard (`page.keyboard`; focus read from `document.activeElement` after every Tab) and mouse for the theme switch

Scripts: `the evidence archive `G1-use-testing/` (owner shared storage; not committed because some screenshots show throwaway QA passwords) m0.py` (log `m0.log`) and `m0_fileinput.py`. ## Proposed issues (`type:usability`)

| # | Title | Severity | Journeys | Detail |
| --- | --- | --- | --- | --- |
| U-M0-1 | No visible focus on the logo upload and Import YAML controls | major | M0-08 | Style the label with `:focus-within`, or use a real button that opens the file input. |
| U-M0-2 | Light-theme focus ring contrast 1.68:1 | major | M0-05, M0-03 | --focus #FFB400 on --bg #F7F8FA fails 3:1 non-text contrast. This is a design-token change, so it may need a CP issue against screens.md. |
| U-M0-3 | Inline editors don't move focus or close on Escape | minor | M0-04 | Move focus to the first field (or heading) of the opened form, close on Escape and return focus. Open the term editor next to the term, or scroll it into view. |
| U-M0-4 | Page title doesn't name the screen | minor | M0-06 | Use "<Screen> · <site title>". The sign-in page and Not Found use "regwatch". |
| U-M0-5 | Not Found page has no shell or way back; /admin home missing | minor | M0-06 | screens.md lists /admin Settings home. |
| U-M0-6 | Shell doesn't adapt under 1024 px | minor | M0-07 | Horizontal scrolling, overlapping title and nav, no menu button below 768 px. |
| U-M0-7 | Focus lost to the page body after Create user and after sign-in | minor | M0-03, M0-01 | Move focus to the status message (which holds the temp password) or to the h1. |
