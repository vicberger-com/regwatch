# Use testing script: M8 Output and delivery

**Tester:** use-testing session, not involved in building M8 (scripted Playwright journeys, headless Chromium from the official Playwright 1.65.1 image pinned by digest `sha256:1507cbfc550a…5579`, driving the repository's own `@playwright/test` 1.65.1 mounted read-only) · **Build:** 0.1.0, the isolated QA stack at http://localhost:8180, with Mailpit at http://localhost:8125. The branch under test is `feat/M7-reports` at `46db174`; the stack's checkout is at `9cfcac0`, and the two differ only in `BACKLOG.md` and the M8 module record. Run on 2026-11-21 from 00:35 to 00:44 UTC. · **Viewport:** 1440 x 900 · **Input method:** mouse (scripted pointer and typing), except M8-09, which is keyboard only · **Round:** 2

Scripts: `/tmp/ut2/m8a.js`, `m8b.js`, `m8c.js`, `mail.js`, `m8print.js`, `kbd.js`, `kbd2.js`, `days.js`, `restore.js` and `pdftext.py` (outside the repository and not committed). The admin password was read only inside the scripts. Sign-in went through the API, so no screenshot shows the sign-in form. Most journeys ran as throwaway analysts created through the admin API, so they would not use up the admin's 20-an-hour output quota. Their passwords existed only in the scripts' memory, and the users were disabled at the end. Screenshots are in `shots/`. Times are the script's wall-clock time, measured from the click on Request until the row shows Done (the list polls every 5 s). The PDF page numbers and markings were read from the PDF text (`pdftext.py`), because no PDF rasteriser is available offline.

**Settings changed and restored** (all through `/admin/settings`, all audited):
- `outputs.allowed_recipient_domains`: `example.org` → `example.org`, `example.com` (00:35) → `example.org` (00:43).
- `outputs.attachment_max_bytes`: 20971520 → 1000 (00:37:07) → 20971520 (00:37:13), to make a delivery fail (M8-06).
- The admin's theme preference: `system` → light, dark and high contrast through the header button → `system` (M8-08).

**Left in place:** the view "Europe 30 days", the test layouts (named "UT2 …"), the output jobs and Mailpit messages, and five disabled `ut2-*@example.org` users. No schedule is left active.
