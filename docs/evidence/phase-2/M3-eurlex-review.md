## Data flows touched
- **Worker to publications.europa.eu:**
  - `discover` sends one `GET https://publications.europa.eu/webapi/rdf/sparql?query=...` with `Accept: application/sparql-results+json`.
  - `fetch` sends `GET https://publications.europa.eu/resource/celex/{celex}` with `Accept: application/xhtml+xml` and `Accept-Language: {content_language}` for each work. Cellar answers 303 to plain http, which `upgraded` rewrites to https.
  - Every request goes through `ctx.fetcher` (`_CountingFetcher`, then `CaptureFetcher`, then `SafeFetcher`), with `allow_hop=_cellar_hop` and the rate held to at most 10 a minute.
  - robots.txt for the origin is read by `RobotsPolicy`; it redirects to op.europa.eu (E-EU-3, E-EU-4).
- **SPARQL JSON to candidates:** `url` (the eur-lex.europa.eu display link built from the CELEX), `title` (`plain_text`), `published_at` (the work date), `external_id` (the CELEX), `language` and `hints["fetch"]` (the Cellar content URL) go to the run manifest, M4, users' browsers, emails and exports.
- **Worker to the object store:** the content body is stored under `raw/{source_id}/{sha256}`, and the manifest under `raw/{source_id}/runs/{run_id}.json`. The SPARQL answer is not stored.
- **Settings to requests:** holders of `sources.manage` write `source.config.params`, which choose the concepts, sectors, exclusion pattern, lookback, limit and content language. The endpoint and the URL templates are fixed. The job's cursor (CP-14) and last success choose the start date.
- **Errors:** `ConnectorError(reason, detail)` goes to `capture_run.error_class` and `error_message`, and into dry-run warnings. `FetchRefusedError` details are replaced by fixed text. Any other exception ends the run as `internal-error` with only its type name.
- **Trust boundary:** the SPARQL answer and the content bodies, statuses and headers, and anything they redirect to, are hostile (8.1).

## Checked and found fine
- **Header allowlist:** names are compared lowered against `accept`, `accept-language`, `if-none-match` and `if-modified-since` (`fetch.py:46`). No Unicode name lowers to one of them. Values must be `str` of at most 256 characters, each between space and `~`, which excludes CR, LF, tab, DEL and non-ASCII. The check runs at the top of `fetch`, before `before_hop`, so a refused header is never sent and takes no rate slot (tested). `Host`, `User-Agent` and `Accept-Encoding` are written after the extras. `trust_env=False` and no cookie jar are unchanged.
- **Upgrades:** only `http` on an exact listed host (lower-cased by `urlsplit`) with port 80 or no port becomes `https` with the default port. Userinfo is dropped, and `parse_target` would refuse it anyway. The upgrade happens before `redirects.append`, the redirect limit and `before_hop(current)`, so the https URL is the one checked and requested. A trailing-dot host or another port is not upgraded and is then refused by `_cellar_hop` (probe I). No upgrade can turn https into http, change the host, or skip a check.
- **SPARQL query building:** the endpoint is a constant, and `sparql_endpoint`, `content_url_template` and `display_url_template` must equal their fixed values (tested, including the integration 422 on `config.params`). Concepts must fully match `http://eurovoc\.europa\.eu/[A-Za-z0-9_]{1,40}`, so no `>`, space, quote or brace can reach the `<...>` IRI. Sectors are single ASCII digits inside a character class. The language is `[A-Z]{3}` (ASCII). The date is a `date.isoformat()` result, and the limit is `int()` of a checked integer. `check` runs again at the start of `discover`. The whole query is one `urlencode`d parameter, so nothing can add parameters or change the path.
- **Exclusion pattern:** RE2 through `compile_pattern`: no backreferences or lookaround, a bounded program size, no zero-width matches, at most 200 characters. It runs on CELEX strings of at most about 35 characters that have already passed `_CELEX`, so its cost is negligible.
- **One query per run, oldest first:** `discover` makes exactly one SPARQL request (tested). The order is `ASC(?date) ?celex`, which is deterministic. The start is the cursor, else the last success, else 30 days back, less `lookback_days` (tested). `resumes` is noted, so `run_connector` moves the cursor to the newest date stored, held at tomorrow.
- **Truncation:** a page of `limit` rows or more adds `truncated` (tested at the boundary). Duplicate rows count towards it, which errs towards "more remain".
- **Hops and hosts:** every request, the SPARQL query, the content, the 303 target and any further redirect, passes `_cellar_hop` (https, host `publications.europa.eu`, no port), through `allow_hop`. `CaptureFetcher` checks it before robots.txt, the rate slot and the request, so a redirect to eur-lex.europa.eu or elsewhere is never contacted and becomes `off-host` with nothing stored (tested). `fetch` checks `hints["fetch"]` with `_cellar_hop` before any request. eur-lex.europa.eu appears only as the display link. Neither the save path, the dry run nor `run_connector` fetches a candidate's `url`.
- **Rate cap:** `min(job.rate_per_minute, 10)` on every request, discovery and content alike. The robots.txt slot uses the same rate. Probe C shows the content requests held to it too: with a sleep that does not wait, the per-host limiter refuses the request after 21 slots (robots.txt, the query and 19 documents), which is past its 120-second wait at 10 a minute.
- **WAF challenges:** `x-amzn-waf-action` on the final answer (headers are lower-cased by httpx) is `blocked-by-provider`, checked before the status, so R-06's `202` challenge is never taken as content. The challenge body is not stored (but see finding 3).
- **Untrusted answer:** the body is capped by SafeFetcher, then by `parse_json` (5 MiB, depth 32) in a thread. Non-object shapes give `malformed-answer` (tested). Every cell is read through `_value`, which accepts only `dict` and `str`. The CELEX must fully match `[0-9][0-9A-Z]{4,20}(\([0-9]{1,3}\))?(-[0-9]{8})?`, and repeats are dropped. The title goes through `plain_text` (cut to 4,000 characters before cleaning, then at most 1,000). Links are built only from the checked CELEX: the display link through `entry_link`, the content link with `quote(safe="()-")`. Nothing else from the answer reaches a candidate. The stored document is Cellar's body under a key built from `source_id` and its hash, with `final_url` on publications.europa.eu.
- **Errors:** every `ConnectorError` detail is a constant or an integer status. `refused-host` is mapped to a fixed `off-host` text. Other `FetchRefusedError`s keep their reason and get fixed text in `run_connector` and the dry run. No response content reaches an error.
- **Save time:** unknown keys, `method` other than `sparql`, booleans for `limit` and `lookback_days`, out-of-range values, an empty or foreign concept list, non-ASCII digits as sectors and an over-long or non-RE2 pattern are all refused (tested). `endpoint_url` is refused for this provider by `check_params`.
